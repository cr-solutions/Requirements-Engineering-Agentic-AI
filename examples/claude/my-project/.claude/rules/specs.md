# Working with feature specs

- Read `requirements.md`, then `design.md`, then `tasks.md` of the ONE feature folder you were pointed at.
- Do not read or modify the spec folders of other features.
- Implement one task at a time, in the order of the dependency graph (waves) at the end of `tasks.md`.
- After a task is done, tick its checkbox in `tasks.md` and keep the `← design.md §x, requirements §y` references intact.
- Log decisions, blockers and progress in the context history file (see `.ai-rules.md`, section "Context History").
